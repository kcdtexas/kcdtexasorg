# Code of Conduct

KCD Texas, including this repository, follows the [CNCF Event Code of Conduct](https://events.linuxfoundation.org/about/code-of-conduct/). Organizers also follow the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report a problem, email the organizers at organizers@kcdtexas.org. You can also contact CNCF directly at conduct@cncf.io.
