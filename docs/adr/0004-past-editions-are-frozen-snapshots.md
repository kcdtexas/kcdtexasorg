# Past Editions are frozen snapshots, not live Sessionize reads

When an Edition ends, its program data from Sessionize is saved into this repository, and from then on the Website reads that saved copy. Old Sessionize events can be edited, closed or deleted, and a Past Edition has to stay exactly as it happened.

## Consequences

- The 2026 snapshot doubles as test data for the Schedule pipeline.
- A snapshot is frozen, but it can still be edited: if a Speaker asks to be removed, their entry is redacted.
- Session abstracts and Speaker bios belong to their authors and are not covered by the Website's text license.
