# Content lives in git and is edited through a git-based editor, not a hosted CMS

All Website content lives in this repository as Markdown and YAML. Organizers who don't write code edit it through a git-based editor, which opens a pull request with a preview link that another Organizer approves. A hosted headless CMS would keep content outside git and add an account, and possibly a bill, that has to be handed over every year. That's the handover risk this project is designed to avoid.

## Considered Options

- **Hosted headless CMS** (Sanity, Contentful, BCMS). A nicer editor, but content lives outside git and the account changes hands every year.
- **Git only, with no editor.** Free, but it makes a developer the bottleneck for every sponsor logo.
